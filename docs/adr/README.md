# ADR(設計判断の記録)

feedlens の設計判断を記録する。コードのコメントには設計判断を書かず、ここに書く。

## 書き方

- ファイル名は `NNNN-短い題名.md`(4桁の連番)。日本語で書く。
- 項目は、状態・背景・決定・検討した代替案・結果・未確認と見直しの条件。
- 状態は「提案」「採用」「廃止」「置換(→ADR-NNNN)」のいずれか。
- 決定を変えるときは、元のADRを書き換えず、新しいADRを足して元の状態を「置換」にする。
- 確認済みのことと未確認のことを分けて書く。
